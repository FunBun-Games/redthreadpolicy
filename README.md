# redthreadpolicy
## update.json — оновлення гри

Гра «Червона нитка» читає цей файл при запуску (https://funbun-games.github.io/redthreadpolicy/update.json).

- `minVersion` — найстаріша версія, у яку ще можна грати. Якщо встановлена версія старша, гра показує вікно «Потрібне оновлення» без кнопки «Пізніше». Зазвичай тут версія, що вже є в App Store, або нижча (за замовчуванням `1.0.0` — нікого не змушує).
- `note_uk`, `note_en` — необов'язковий текст для вікна оновлення (порожньо — стандартний текст).
- `latest` — необов'язково: номер новішої версії, якщо App Store його ще не показує.

Про нову версію в App Store гра дізнається сама й нагадує раз на день, цей файл для цього міняти не треба.
